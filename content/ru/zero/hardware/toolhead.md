# Распиновка тулхеда и SWD-хедер

Переписано с официального pin-definition от Sovol (`Motherboard/Extra_Pin_definition.pdf` в [Sovol3d/SOVOL-ZERO](https://github.com/Sovol3d/SOVOL-ZERO)) — смотри тот PDF ради полной картинки платы с подписями. MCU тулхеда — это STM32F103 (`extruder_mcu`), шелкография платы `MINI-ZJB-V1.0`.

## Коннекторы

| Коннектор | Пины (как на шелкографии) |
| --- | --- |
| Вентилятор охлаждения | `24V` · PWM `PA6` · FG `PA1` |
| Вентилятор (верхний) | `24V` · PWM `PA7` · FG `PA2` |
| Вентилятор модели | `24V` · PWM `PB0` · FG `PA3` |
| Термистор сопла | `PA5` · `GND` |
| Нагревательный блок | `GND` · `24V` · `PB1` · `GND` · `PA4` |
| Нагреватель | `24V` · MC_HEATER `PB7` |
| Питание 24 В | `GND` · `24V` |
| Мотор экструдера | DIR `PA9` · STEP `PA8` · EN `PA11` · UART `PA12` |
| Концевик оси X | `PA10` · `GND` · `5V` |
| Концевик / датчик | `5V` · `GND` · `PC15` · `PC14` |
| **Датчик eddy current** | `5V3` · `GND` · **`PB10` (SCL)** · **`PB11` (SDA)** |
| Связь с мейнбордом (CAN) | CANL · `GND` · CANH  (CAN_R `PB8` · CAN_T `PB9`) |
| **SWD-хедер** (шелк `5V3 IO CK G`) | `5V3` = 3.3 В · `IO` = SWDIO (`PA13`) · `CK` = SWCLK (`PA14`) · `G` = GND |

Коннектор eddy-датчика выводит `PB10`/`PB11`. На mainline Klipper гоняй LDC1612 через **software I2C** на этих пинах, а не через аппаратный `i2c2` — см. [страницу конфига Klipper]({{< relref "/zero/application/klipper-config" >}}).

SWD-хедер — это то, что прошиваешь один раз, чтобы забутстрапить тулхед. Разводка и процедура openocd — на [странице прошивки]({{< relref "/zero/firmware/flashing" >}}).

## Этот тулхед общий с SV08 Max

У Zero и SV08 Max **один и тот же модуль тулхеда** — идентичные партномера в CAD BOM, попиновые заводские конфиги, тот же boot-UUID Katapult (`61755fe321ac`), и байт-в-байт идентичный pin-definition PDF (`Extra_Pin_definition.pdf`, md5 `b187deb9362b339f55287591f3d510f1` в обоих официальных репозиториях). Та же плата (`MINI-ZJB-V1.0`), тот же STM32F103, та же eddy-проба (LDC1612), тот же акселерометр LIS2DW.

Max отличается только тем, как голова *распаяна и смонтирована*, а не платой:

| | Zero | SV08 Max |
| --- | --- | --- |
| Обдув детали | 1 турбина (5020, `fan0` на `PB0`) | 2 турбины: 5020 `PB0` + **3010 `fan1` на `PA7`** |
| `max_temp` хотенда | 355 | 310 (кап прошивки) |
| Каретка X / крепление | салазки Zero | адаптер под машину покрупнее |

Ключевая деталь: `PA7` («Fan top») есть на плате Zero, но оставлен нераспаянным. Max вешает на него второй вентилятор. Поэтому эта страница распиновки — компонент, а не Zero-only факт: вторая модель переиспользует её дословно, и единственная дельта конфига — добавить или убрать `fan1` на `PA7`.

Не общее: **мейнборд** и его device tree. Zero (`MB_JC_XL_500`, 1×Z) и Max (`MB_JC_XZ_500`, 4×Z quad-gantry, AC-стол, feed-порт) — разные PCB одной платформы H616 + STM32H750, с разными DTS/dtb. Мейнборды как есть не взаимозаменяемы.
