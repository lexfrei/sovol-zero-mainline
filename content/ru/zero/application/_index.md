# Приклад — слой 4

Хост Klipper, Moonraker, веб-UI, crowsnest, допы — и набор конфигов, который их связывает. Это слой, который ты трогаешь чаще всего, и его конфиг — самый волатильный артефакт во всей машине: блоки калибровки, макросы и saved variables меняются с каждой сессией тюнинга. Держи набор конфигов в git и пересохраняй после каждой сессии.

Всё выше Klipper — уже сток upstream, так что этот слой — в основном установка и настройка, а не портирование кода:

- **[Стек KIAUH]({{< relref "kiauh" >}})** — установка Klipper (master), Moonraker, Mainsail, Crowsnest, плюс два постустановочных фикса, которые кусают на этой плате.
- **[Конфиг Klipper]({{< relref "klipper-config" >}})** — перевод конфига с вендорского: eddy на software I2C, tap, `homing_override`, и вендорские модули под выброс.
- **[Плагины]({{< relref "plugins" >}})** — `sovol_codes`, `scipy` для eddy-пробы, timelapse, Shake&Tune.
- **[Калибровка]({{< relref "calibration" >}})** — drive current, таблица частота→высота у eddy, порог tap, input shaper, и контролируемая первая печать.
- **[Допы]({{< relref "extras" >}})** — опциональное железо, проверенное на реальной машине: USB WiFi-донгл, датчик филамента BTT SFS V2.0, и пара бэкапов, которая делает эксперименты с ядром обратимыми.
