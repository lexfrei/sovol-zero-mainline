# Переустановка ОС без eMMC-ридера

Нет ридера, и не хочешь снимать модуль? Можно положить свежую ОС на eMMC прямо с работающей платы. Фокус в слоте microSD: H616 грузит SD раньше eMMC, так что ты загружаешь свежий образ с карты и оттуда клонируешь его на eMMC.

Обходного пути по USB нет — плата не выводит порт USB-C / OTG, так что обычный маршрут `sunxi-fel` + U-Boot `ums`, чтобы достать eMMC по USB, отпадает (смотри [почему FEL отпадает]({{< relref "armbian" >}}#the-board-the-emmc-and-why-fel-is-off-the-table)). Загрузка с SD и клонирование — единственный путь без ридера.

## Загрузись с SD, клонируй на eMMC

```text
Sovobian on microSD  →  boot from SD  →  armbian-install  →  system now on eMMC
```

1. **Запиши образ Sovobian на microSD** (Etcher, Armbian Imager или `dd`). Используй **Sovobian**, а не обычный образ BTT CB1 — у Sovobian оверлей eMMC 40 МГц уже запечён. Загрузка стокового образа CB1 и его клонирование установили бы device tree eMMC на 120/150 МГц, который "may appear to boot and then fail unpredictably" (смотри [разницу CB1]({{< relref "armbian" >}}#what-almost-a-cb1-actually-means)).
2. **Вставь карту и включи питание.** Плата грузится с SD раньше eMMC. Сделай настройку первой загрузки — дружелюбный способ на [странице простой установки]({{< relref "quickstart" >}}).
3. **Клонируй работающую SD-систему на eMMC:**

   ```bash
   sudo armbian-install
   ```

   Выбери вариант, который ставит систему на eMMC и грузится с неё («Boot from eMMC — system on eMMC»; на старых образах этот инструмент — `nand-sata-install`). Он копирует текущую работающую SD-систему, включая `/boot`, на eMMC.
4. **Выключи питание, вынь SD, включи.** Плата теперь грузит свежеустановленную систему с eMMC.

Дружелюбный TUI делает то же самое, если тебе удобнее пройти по меню: `armbian-config` → System → install to eMMC.

> [!WARNING]
> **Требует проверки именно на Zero.** Маршрут загрузка-с-SD + `armbian-install` подтверждён на SV08 (тот же хост H616, та же линия CB1, тот же boot ROM) и одобрен собственными доками Sovobian, но Zero-специфичной записи не нашлось — трактуй точную формулировку меню и клонирование как воспроизведённые в другом месте, а не проверенные на Zero. Две вещи, которые надо проверить после клонирования: что eMMC работает на [проверенном клоке 37.5 МГц]({{< relref "armbian" >}}#first-boot-verifying-the-emmc-clock) (то есть оверлей `overlay-user/` доехал до eMMC), и что плата всё ещё поднимается на одной eMMC. Сохрани SD-карту — без OTG это твой единственный путь спасения, если установка на eMMC пойдёт не так.

## Или просто останься на SD

Ничто не заставляет ставить систему на eMMC. Многие гоняют Zero целиком с microSD, а стоковый модуль eMMC оставляют открученным на полке как заводской бэкап. Используй хорошую карту — периодические сбои загрузки с SD встречаются, и обычная причина — глючная карта.
